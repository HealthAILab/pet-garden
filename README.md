# 萌宠乐园

双击 `启动家庭宠物园.bat` 即可使用，无需安装、无需联网。

功能包括：家庭成员、家务任务与爱心奖励、成员和任务删减、四种宠物互动、47 种宠物的 8 个成长形态、8 级成长体系、自动状态变化，以及 JSON 数据备份与恢复。状态条和照顾按钮支持鼠标悬停查看具体规则。

成员和任务条目右侧的 `×` 用于删除。删除成员会同时删除分配给该成员的任务，但不会倒扣已经获得的宠物成长值。

数据保存在当前浏览器的 `localStorage` 中。更换浏览器或清理数据前，请从页面右上角设置导出备份。

## 图片使用范围

`assets/pets` 中的图片由你提供的“酷课堂-班级宠物园”安装包解包得到，仅供本机家庭使用。安装包中没有发现允许再次分发图片的独立授权，因此不要把原图随项目公开发布或用于商业用途；如需发布，请取得权利人许可或换成自有/已授权素材。

通过页面顶部“领养宠物”进入领养中心，可以浏览全部宠物图片、选择品种并命名；名字默认使用宠物品种名称，也可以修改。确认领养后显示宠物蛋，完成任务积累成长值，达到 30 时孵化为所选宠物。默认今日任务是“读英语20分钟”和“阅读30分钟”，每项奖励5爱心。Lv.1–Lv.8 的成长阈值分别为 30、100、220、400、650、950、1350、1850。
